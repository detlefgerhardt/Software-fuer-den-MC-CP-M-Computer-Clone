**C# Tools**

Dieses Verzeichnis enthält die in C# geschriebenen Tools, die ich in Zusammenhang mit der MC CP/M-Computer Entwicklung verwende.

**CPM-Tools** ist ein Sammelprojekt für einige Tools.

Die Projekte sind derzeit alle noch mit .NET Framework 4.6 programmiert. Das verwende ich standardmäßig, damit die Programme auch noch unter älteren Windows-Versionen funktionieren.
Eine Überführung der Kommandozeilen-Tools nach .NET8 ist geplant. Dann sind sie auch unter DOTNET unter Linux lauffähig.
