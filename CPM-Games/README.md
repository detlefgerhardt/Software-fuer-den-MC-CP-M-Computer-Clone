# Spiele für dem den MC CP/M Computer
Hier sollen nach und nach einige auf dem MC CP/M-Computer getestete Spiele abgelegt werden. Darunter auch einige selbstprogrammierte Spiele - in der Regel Neuimplementierungen alter Spieleklassikern wie Hammurabi, Collosal Cave Adventure, Lunar Lander usw.
